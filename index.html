第三章

กฎระเบียบ

The Code — 掟

เคารพลำดับชั้นและครูอาจารย์

นักเรียนทุกคนต้องให้เกียรติครู ฝ่ายปกครอง และรุ่นพี่ตามระเบียบโรงเรียน การไม่เคารพถือเป็นความผิดร้ายแรง

ห้ามใช้ความรุนแรงนอกพื้นที่ที่กำหนด

ข้อพิพาทระหว่างแก๊งหรือนักเรียนต้องยุติในพื้นที่และเวลาที่ฝ่ายปกครองอนุญาตเท่านั้น

แต่งกายให้ถูกระเบียบโรงเรียน

ชุดนักเรียนต้องเรียบร้อยตามแบบที่กำหนด งดการดัดแปลงเครื่องแบบโดยไม่ได้รับอนุญาต

ห้ามพกอาวุธเข้าบริเวณโรงเรียน

การพกพาสิ่งของอันตรายเข้าเขตโรงเรียนถือเป็นความผิดขั้นรุนแรงที่สุด

ปฏิบัติตามคำสั่งฝ่ายปกครองเมื่อมีการเรียก

เมื่อถูกเรียกพบฝ่ายปกครองต้องเข้าพบทันที การหลบหนีจะเพิ่มระดับความผิด

ระดับความผิดตัวอย่างบทลงโทษ
ระดับ 1แต่งกายผิดระเบียบ, มาสายตักเตือนด้วยวาจา + บันทึกชื่อ
ระดับ 2ทะเลาะวิวาทเล็กน้อย, หนีเรียนตัดคะแนนความประพฤติ + แจ้งผู้ปกครอง
ระดับ 3ก่อเหตุรุนแรงในพื้นที่ต้องห้ามพักการเรียนชั่วคราว
ระดับ 4พกอาวุธ, ทำร้ายครู/ฝ่ายปกครองไล่ออกทันที
